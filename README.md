# Manufacturing Data Platform

An end-to-end data engineering portfolio project based on a realistic manufacturing business workflow.

## Project Goal

The goal of this project is to design and build a scalable data platform that processes manufacturing data from quotation through production, delivery and invoicing.

## Business Process

Customer Enquiry  
→ Quotation  
→ Purchase Order  
→ Material Planning  
→ Production Scheduling  
→ Laser Cutting  
→ Fabrication  
→ External Processing  
→ Delivery  
→ Invoice

## Planned Technology Stack

- Microsoft Fabric
- Azure Data Factory
- Azure Data Lake
- Azure Databricks
- PySpark
- Python
- SQL
- Delta Lake
- Power BI
- GitHub

## Planned Architecture

Source Data  
→ Raw Layer  
→ Bronze Layer  
→ Silver Layer  
→ Gold Layer  
→ Data Warehouse  
→ Power BI
